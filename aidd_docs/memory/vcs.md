# VCS

Les conventions de versionnement que ce projet suit : branches, commits et plateforme.

## Setup

- Branche principale : `main`
- Plateforme : GitHub (remote `origin`)

## Branches

- Format : `<type/ticket-short-description>`
- Types en usage : `feature`, `fix`, `chore`

## Commits

- Convention : conventional commits
- Format : `type(scope): description` (ex. `feat(opencode): update model configurations`)
- Règles : impératif, description concise

## Commit Strategy

IA auto commit : `never` — l'IA ne commite jamais sans demande explicite de l'utilisateur.
